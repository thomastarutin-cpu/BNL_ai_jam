# LaserBase

A searchable catalogue of high-power lasers and related user facilities.

**Live app:** <https://bnlaijam-kadecna4jisn7pvqmsdtvw.streamlit.app/>

LaserBase is a database effort for organizing source-backed information on
high-power lasers and related user facilities. It helps researchers compare
facility capabilities, find representative operating parameters, and maintain
records on instruments worldwide.

This project was conducted as part of the Brookhaven National Laboratory (BNL)
2026 AI Jam, where it was awarded first prize. All sources and entries were
verified by hand. More on the project, teams, and acknowledgements is on the
**About** page of the app.
